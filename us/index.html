Products

Protecting every layer, from end devices to the cloud

TMAF

Trusted Multi-Agent Framework
An AI security platform that detects and controls anomalous behavior in multi-agent systems connected to external generative AI.

DPF

Dialect Perimeter Filter
A next-generation security system that protects network perimeters using a unique Dialect-based communication scheme.

CC-BOX

Confidential Computing Platform
A confidentiality-assured security platform that protects not only stored data but also data in use during computation.

CC-SBOM

Confidential Computing SBOM
A security solution that supports SBOM generation in conjunction with the CC-BOX secure execution environment.

Outerstellar

Hardware-based Instruction-flow Safety Monitor
A security solution that ensures integrity by monitoring a system's instruction flow using hardware, based on the Interstellar research published at ACM CCS.
