What Is CC-SBOM?

Achieving software supply chain security and confidentiality at the same time

Confidential Computing SBOM

An SBOM (Software Bill of Materials) is a list of all components that make up a piece of software and is central to vulnerability management and supply chain security. However, providing source code or binaries to an external service to generate an SBOM can leak confidential information.

CC-SBOM generates SBOMs inside the Trusted Execution Environment (TEE) of CC-BOX, providing accurate SBOMs and real-time vulnerability information without exposing the user's source code or trade secrets.

SBOM Supply Chain Security Vulnerability Management TEE-Based Analysis

What Is an SBOM (Software Bill of Materials)?

An SBOM is a list of all open-source software, third-party libraries, and internal components included in a piece of software. Major countries and regions require SBOM submission through measures such as the U.S. Executive Order (EO 14028) and the EU CRA, and supply chain vulnerability incidents such as Log4Shell have sharply raised the importance of SBOMs. CC-SBOM generates these SBOMs securely without exposing source code.

Key Features

Four core capabilities for secure SBOM management

Prevention of User Confidential Information Leakage

During SBOM analysis, confidential information such as source code, binaries, and trade secrets is processed in the CC-BOX Trusted Execution Environment (TEE) and fully protected so that even the service provider cannot access it.

Real-Time Vulnerability Management Service

Generated SBOMs are checked in real time against vulnerability databases such as CVE and NVD, with immediate alerts when new vulnerabilities are found. It also responds quickly to zero-day attacks such as Log4Shell.

Software Asset and IP Protection

When using an SBOM analysis service on a cloud or external server, the entire analysis process is protected by the CC-BOX TEE so that software assets and intellectual property are not exposed to the server operator.

Specialized Support for Regulated Sectors

Provides SBOM formats and reports specialized for regulated industries where SBOM mandates are underway, such as medical device software (IEC 62304), financial systems, automotive OEMs (UNECE WP.29), and industrial control systems (IEC 62443).
