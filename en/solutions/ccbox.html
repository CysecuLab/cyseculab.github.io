What Is CC-BOX?

Complete data confidentiality that protects even data in use

Confidential Computing Platform

Typical security solutions protect stored data (Data at Rest) and data in transit (Data in Transit), but data in use (Data in Use) is exposed in plaintext in memory.

CC-BOX uses a Trusted Execution Environment (TEE) to fully guarantee data confidentiality even during computation. Even cloud server operators cannot access data being processed.

Key Features

Four core capabilities for complete data confidentiality

Protection of Data in Use

Based on a Trusted Execution Environment (TEE), complete confidentiality is guaranteed even while data is being computed in memory. No one, including cloud providers and server administrators, can access data being processed.

Financial and Medical Regulatory Compliance

Technically guarantees the level of confidentiality required by data protection regulations such as GDPR, HIPAA, and Financial Supervisory Service rules. Audit logs and certificates for regulatory compliance are generated automatically.

Intellectual Property (IP) Protection

When core intellectual property such as AI models, algorithms, and source code runs on cloud or third-party platforms, the IP is securely protected even from the platform operator.

Easy Adoption

CC-BOX can be applied with minimal changes to existing application code, keeping the adoption burden low. It supports a wide range of cloud environments and on-premises systems.
