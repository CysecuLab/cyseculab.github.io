What Is Outerstellar?

Blocking with hardware the threats that software cannot stop

Hardware-based Instruction-flow Safety Monitor

Advanced threats that attack the OS kernel, such as rootkits and kernel exploits, are fundamentally limited in how well software-based security solutions can detect and defend against them. Once an attacker takes control of the OS, the software monitor itself can be bypassed.

Outerstellar monitors the instruction flow at the CPU hardware level and immediately detects integrity violations even when the OS has been compromised or manipulated. It is based on the Interstellar research published at ACM CCS.

Outerstellar is based on the "Interstellar" research paper published at ACM CCS (Conference on Computer and Communications Security), one of the world's top security conferences. Implemented with core technology validated by both academia and industry, it combines academic rigor with practical utility.

Why It Must Be Hardware-Based

Overcoming the limits of software monitors with hardware

Conventional Approach

Software-Based Monitoring

  • If the OS is compromised, the monitor can be bypassed along with it
  • The monitor itself can be disabled by a rootkit
  • Limited ability to detect malicious code inside the OS kernel
  • Attackers can modify or delete the monitoring logic
Outerstellar

Hardware-Based Monitoring

  • Monitors from a hardware layer independent of the OS
  • Software cannot tamper with or bypass the monitor
  • Directly verifies CPU instruction flow at the hardware level
  • Can detect even after the OS has been fully compromised

Key Features

Four core capabilities for hardware-level integrity assurance

Hardware-Level Instruction Flow Monitoring

Tracks the CPU's instruction execution flow (Control Flow) in real time at the hardware level. Any anomalous behavior that deviates from the normal execution path is detected and blocked immediately.

Real-Time OS Kernel Integrity Verification

Verifies in real time the integrity of key areas of the operating system kernel, such as code regions, data structures, and the system call table. Attacks such as rootkits and kernel exploits are detected immediately.

Hardware Security That Software Cannot Tamper With

Because the monitoring system itself is implemented in hardware, it is fundamentally impossible for malicious software or attackers to disable or bypass the monitoring function.

ACM CCS "Interstellar" Validated Technology

Applies technology that has been rigorously validated academically, based on research published at ACM CCS, one of the world's top security conferences. A trustworthy solution backed by both theoretical security proofs and experimental validation.
