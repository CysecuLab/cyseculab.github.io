About Us

CySecuLab

Based on the Cyber System Security Lab at KAIST Graduate School of Information Security

Founded in 2023, CySecuLab Co., Ltd. combines the security research capabilities of KAIST Graduate School of Information Security with innovative ideas to research and develop future information security technologies. From end devices to cloud environments, we ensure secure exchange and execution across every connected space.

TMAF

Trusted Multi-Agent Framework

An AI security platform that detects and controls a wide range of anomalous behavior in multi-agent systems connected to external generative AI, including confidential information leakage, prompt injection, unauthorized agent infiltration, and harmful output generation.

  • Privacy Guard — Detects, substitutes, pseudonymizes, and encrypts confidential information
  • Safety & Policy Guard — Detects and controls Prompt Injection and Jailbreak attempts, blocks harmful output
  • Agent Trust Mesh — Agent authentication, blocking of unauthorized agents, secure communication
  • Confidential Runtime — Runs sensitive agents in a TEE-based protected environment
Anomaly Detection Multi-Agent Security Prompt Injection Defense Confidential AI

DPF

Dialect Perimeter Filter

A next-generation security system that protects network perimeters using a unique Dialect-based communication scheme.

  • Dialect-based device authentication and Zero Trust implementation
  • Dialect of Things - network security for IoT environments
  • Operating system / kernel-level networking security
  • Built on remote memory system security research
KISA Rapid Verification Certified (CySecuLab Co., Ltd., Korea) Network Security Zero Trust IoT Security Korean Patent Registered (exclusive licensee: CySecuLab Co., Ltd., Korea)

CC-BOX

Confidential Computing Platform

A confidentiality-assured security platform for data privacy and security regulatory compliance. It protects not only stored data but also data in use during computation.

  • Protection of data in use - confidentiality guaranteed during execution
  • Regulatory compliance support for financial, medical, and corporate confidential data
  • Protects intellectual property (IP) from service platform providers
  • Easy to apply, supporting a wide range of systems
Confidential Computing Data Privacy Compliance
Learn more

CC-SBOM

Confidential Computing SBOM

A security solution that supports generation of a Software Bill of Materials (SBOM) in conjunction with the CC-BOX secure execution environment.

  • Prevents leakage of user confidential information (such as source code)
  • Provides real-time vulnerability management service
  • Protects software assets and IP from cloud and server owners
  • Specialized for regulated sectors such as healthcare, finance, OEM, and industrial control systems
SBOM Supply Chain Security Vulnerability Management

Outerstellar

Hardware-based Instruction-flow Safety Monitor

A security solution that ensures integrity by monitoring a system's instruction flow using hardware. It is based on the Interstellar research published at ACM CCS.

  • Hardware-level instruction flow monitoring
  • Real-time verification of OS kernel integrity
  • Hardware-based security that software cannot tamper with
  • Technology validated at a top security conference (ACM CCS)
